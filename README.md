# Лист — студенческие бейджи

Локальный редактор бейджей. Данные и фотографии остаются в хранилище браузера; приложению не нужны внешние сервисы, шрифты или изображения.

## Запуск

- `npm install` — установить зависимости проекта.
- `npm run dev` — открыть редактор в режиме разработки.
- `npm run build` — собрать автономную версию в `dist/index.html`. После сборки этот файл можно открыть на компьютере без интернета.

## Печать

В меню «Печать» сначала выберите лицевую сторону, затем оборотную. Для совмещения переверните лист слева направо, сохранив верхний край. В окне печати выберите формат A4, масштаб 100%, поля «Нет» и включите печать фона.

Сетка рассчитана на 8 бейджей по 96 × 67 мм на листе A4. Для точного совмещения рекомендуется сначала проверить печать на обычной бумаге.
