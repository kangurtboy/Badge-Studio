# Badge Studio

> Локальное веб-приложение для визуального создания, редактирования и двухсторонней печати студенческих бейджиков.

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшн
npm run build
```
