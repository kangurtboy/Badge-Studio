# Badge Studio

Badge Studio — локальное оффлайн-ориентированное веб-приложение для визуального создания, редактирования и двухсторонней печати студенческих бейджиков.

## Назначение
Приложение заменяет рутинную ручную работу в графических редакторах (например, Adobe Photoshop) удобным специализированным инструментом для сотрудников учебных заведений (колледжей, вузов).

## Ключевые возможности (MVP)
- **Визуальный редактор карточек** на базе HTML5 Canvas (Fabric.js).
- **Двусторонняя структура бейджика**: независимые лицевая и обратная стороны.
- **Flip Card Animation**: реалистичный плавный 3D-переворот карточки в интерфейсе (с мгновенным синхронным переворотом всех карточек на листе).
- **Редактор листа A4**: автоматическая и ручная раскладка карточек (2, 3, 4 колонки), направляющие и метки обрезки.
- **Точная печать**: правильное совмещение лицевой и обратной сторон при двухсторонней печати, калибровка смещений (X/Y), отключение элементов интерфейса при печати через CSS Print Media.
- **Оффлайн и безопасность**: 100% локальная работа без внешних серверов и облаков; персональные данные студентов и фото сохраняются в IndexedDB браузера.
- **Поддержка кириллицы и таджикского языка** (Ғ, Ӣ, Қ, Ӯ, Ҳ, Ҷ).
- **История действий**: Undo/Redo и автосохранение.

## Запуск
```bash
npm install
npm run dev
```
Приложение запускается в браузере по адресу `http://localhost:3000`.
