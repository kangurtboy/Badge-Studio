# Архитектура проекта Badge Studio

## 1. Общий обзор архитектуры
Badge Studio спроектирован по модульной бессерверной компонентной модели (offline-first SPA).
Все данные обрабатываются в браузере клиента, сохраняются в IndexedDB и визуализируются через Fabric.js.

```
Badge Studio Application
┌─────────────────────────────────────────────────────────────┐
│ Header (Управление проектом, режимы, статус, Undo/Redo)     │
├───────────────┬─────────────────────────────┬───────────────┤
│ Sidebar       │ Canvas Viewport             │ Properties    │
│ (Список       │ - Badge Editor (Лицевая/    │ Panel         │
│  карточек,    │   Обратная с 3D Flip)       │ (Инспектор    │
│  добавление,  │ - A4 Sheet Editor           │  выделенного  │
│  поиск)       │ - Print Preview             │  элемента)    │
├───────────────┴─────────────────────────────┴───────────────┤
│ Floating Bar (Стороны, Flip 3D, Зум, Навигация)             │
└─────────────────────────────────────────────────────────────┘
          │                   │                   │
    [Storage Layer]    [Editor Engine]     [Printing Engine]
      IndexedDB           Fabric.js          CSS Print Media
     LocalStorage       Canvas Objects       Alignment Engine
```

## 2. Модули системы

### 2.1. Хранилище (`src/storage/`)
- `indexedDB.js`: Персистентное хранилище карточек, проектов и бинарных данных фото (Blob / DataURL). Неблокирующий доступ.
- `autosave.js`: Механизм debounced-автосохранения с индикатором статуса («Сохранено», «Сохранение...», «Ошибка»).
- `recovery.js`: Механизм автоматического восстановления последнего рабочего состояния при повторном открытии страницы.

### 2.2. Движок редактора (`src/editor/`)
- `canvas.js`: Инициализация и менеджмент Fabric.js Canvas для лицевой и обратной сторон.
- `elements.js`: Фабрика добавления текстовых блоков, фото с масками, логотипов, фигур, линий, QR-кодов.
- `selection.js`: Отслеживание активного объекта и синхронизация с панелью свойств.
- `transformations.js`: Масштабирование, вращение, выравнивание (по левому краю, центру, правому краю, вертикали).
- `history.js`: Стек состояний Undo/Redo для отмены действий пользователя.

### 2.3. Двусторонний бейджик и анимация (`src/animation/`, `src/components/BadgeEditor/`)
- Контейнер карточки с `perspective: 1200px`.
- Внутренний контейнер с `transform-style: preserve-3d; transition: transform 0.4s ease-in-out;`.
- Лицевая грань (`front-face`) и обратная грань (`back-face` с `transform: rotateY(180deg)`).
- Независимые холсты Fabric для лицевой и обратной сторон.

### 2.4. Редактор листа A4 и Печать (`src/printing/`, `src/components/A4Editor/`)
- Расчёт геометрии листа A4 (210×297 мм).
- Автоматический расчёт колонок и строк под заданные габариты бейджиков (90×55, 85×55, custom) с учётом полей и зазоров.
- Двусторонняя печать с точным позиционированием:
  - Лицевой лист;
  - Обратный лист с калибровкой смещения (X/Y offset) и переворотом (короткий / длинный край).
- `@media print` стили: изолированный печатный контейнер, скрытие всех панелей и кнопок UI.

### 2.5. Компоненты UI (`src/components/`)
- `Header`: панель команд и переключения режимов (`editor`, `a4`, `print`).
- `Sidebar`: список карточек студентов с превью, добавление, дублирование, удаление.
- `BadgeEditor`: рабочая область карточки с сеткой и направляющими.
- `PropertyInspector`: правая колонка для редактирования свойств выделенного элемента (текст, шрифт, размер, цвет, координаты, порядок слоёв).
