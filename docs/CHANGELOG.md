# История изменений (CHANGELOG)

Все значимые изменения проекта Badge Studio документируются в этом файле.

## [0.6.0] - 2026-11-05
### Добавлено
- **Phase 6 — Сохранение данных (IndexedDB, Autosave, Backup/Restore)**:
  - `RecoveryManager` (`src/storage/recovery.js`): модуль экспорта и импорта резервных копий проекта в файл `.json` с сохранением всех настроек, карточек и изображений.
  - Оценка дискового пространства и квот хранилища браузера (`navigator.storage.estimate`) с отображением занятого объема в окне настроек.
  - Защита от случайной потери данных: диалоги подтверждения при удалении карточек студентов и при сбросе проекта к исходному шаблону.
  - Надежное восстановление последней сессии из базы IndexedDB при повторном открытии вкладки или перезапуске браузера.
  - Живая индикация статуса сохранения в шапке приложения.

## [0.5.0] - 2026-11-05
### Добавлено
- **Phase 5 — Редактор листа A4**:
  - `SheetLayoutEngine` (`src/printing/layout.js`): геометрический движок для расчета размещения карточек на формате A4 (210 × 297 мм) с автоматическим и ручным расчетом колонок (авто, 2, 3, 4), строк, полей листа и центрирования сетки.
  - Поддержка книжной (`portrait`) и альбомной (`landscape`) ориентации листа A4.
  - Генерация угловых меток обрезки (Crop Marks) в векторе SVG для точной нарезки карточек после печати.
  - Диагностическая строка с отображением вместимости страницы, количества колонок/строк и предупреждением, если выбранный размер карточки превышает полезную область листа.
  - Пагинация листов (Стр. 1 из N) при количестве карточек, превышающем вместимость одного листа.
  - Индивидуальные двусторонние 3D-миниатюры студентов на листе с кликом для перехода в редактор.

## [0.4.0] - 2026-11-05
### Добавлено
- **Phase 4 — Работа с фотографиями студента**:
  - `PhotoEditorModal` (`src/components/PhotoEditor/PhotoEditorModal.js`): интерактивное диалоговое окно для кадрирования, панорамирования мышью и настройки фотографии перед применением.
  - Формы масок рамки: скругленная (`rounded`), круглая (`circle`), прямоугольная 3:4 (`rect`), квадратная 1:1 (`square`).
  - Поворот на 90 градусов по часовой стрелке и ползунок масштабирования зума от 50% до 300%.
  - `applyImageFilters` (`src/photo/adjustments.js`): пиксельные локальные фильтры яркости (-50..+50), контрастности (-50..+50), насыщенности (-50..+50) и черно-белый режим (оттенки серого).
  - Поддержка перетаскивания файлов фотографий (Drag-and-Drop) из Проводника Windows напрямую на рабочую область бейджика.
  - Кнопка «Обрезка, рамка и фильтры» в инспекторе свойств при выборе элемента фотографии для редактирования существующего снимка.

## [0.3.0] - 2026-11-05
### Добавлено
- **Phase 3 — Лицевая и обратная стороны и 3D Flip Card**:
  - Полное разделение лицевой (`front`) и обратной (`back`) граней карточки с изоляцией событий мыши Fabric.js (`pointer-events: none` для неактивной стороны для предотвращения ложных кликов через слой).
  - Аппаратное ускорение CSS 3D Transform (`translate3d(0, 0, 0)`, `perspective: 1400px`, `backface-visibility: hidden`) без мерцания и артефактов перекрытия граней.
  - Синхронизированные кнопки переключения сторон («Лицевая сторона», «Обратная сторона») и кнопка «Перевернуть» в нижней плавающей панели.
  - Массовый переворот всех карточек на листе A4: кнопки «Лицевые стороны», «Обратные стороны», «Перевернуть все» с индивидуальным рендерингом данных студентов для обеих сторон в 3D.
  - Поддержка мгновенного переключения сторон при отключении 3D-анимации в настройках (`no-animation` класс).

## [0.2.0] - 2026-11-05
### Добавлено
- **Phase 2 — Визуальный редактор бейджика**:
  - `AlignmentGuidelines` (`src/editor/guidelines.js`): умная магнитная привязка к центру карточки (по X и Y) и к безопасным полям с отрисовкой вспомогательных красных пунктирных направляющих при перемещении объектов.
  - `ElementFactory` (`src/editor/elements.js`): фабрика для динамического создания текстовых блоков, прямоугольников со скруглением, кругов, линий и загрузки растровых изображений (JPEG, PNG, WebP).
  - `CanvasTransformations` (`src/editor/transformations.js`): функции геометрического выравнивания (по левому краю, по горизонтальному центру, по правому краю, по верхнему краю, по вертикальному центру, по нижнему краю).
  - Клонирование и дублирование объектов со сдвигом координат (кнопка копирования и сочетание клавиш `Ctrl+D`).
  - Полноценное 4-уровневое управление слоями: «На самый верх», «На шаг вперед», «На шаг назад», «В самый низ».
  - Живая синхронизация координат X/Y и габаритов W/H в панели свойств при перетаскивании и масштабировании на холсте без потери фокуса ввода.
  - Загрузка локальных фото и логотипов с диска через диалоговое окно файловой системы.

## [0.1.0] - 2026-11-05
### Добавлено
- **Phase 0 — Подготовка проекта**:
  - Инициализирован проект на Vite 6, настроен `vite.config.js` с алиасами для `fabric` и `lucide`.
  - Установлены и проверены библиотеки `fabric` (Fabric.js 7) и `lucide`.
  - Создан полный комплект технической документации в каталоге `docs/`: `PROJECT.md`, `SPECIFICATION.md`, `ARCHITECTURE.md`, `TODO.md`, `CHANGELOG.md`, `AGENT_RULES.md`, `PRINTING.md`.
  - Разработан временный нейтральный шаблон колледжа с лицевой и обратной сторонами (`defaultFront.js`, `defaultBack.js`), поддерживающий кириллицу и таджикские символы (Ғ, Ӣ, Қ, Ӯ, Ҳ, Ҷ).
- **Phase 1 — Основной интерфейс**:
  - `Header`: логотип Badge Studio, индикатор статуса автосохранения («Сохранено», «Сохранение...», «Ошибка»), кнопки Undo/Redo, кнопка нового бейджика, вызов настроек и переключатель режимов.
  - `Sidebar`: список карточек студентов с бейджем количества, строкой поиска по ФИО/ID, миниатюрами, действиями добавления, дублирования и безопасного удаления.
  - `BadgeEditor`: центральная рабочая область с холстами Fabric.js, сеткой, масштабированием и 3D Flip Card контейнером (`perspective: 1400px`, `rotateY(180deg)`).
  - `PropertyInspector`: правая панель с быстрыми кнопками добавления элементов (Текст, Фото, Прямоугольник, Круг), инспектором выделенного объекта (X, Y, W, H, угол, прозрачность, шрифт, размер, цвет, начертание, выравнивание, заливка, обводка, слои) и глобальными параметрами бейджика (стандарты 90×55, 85×55, цвет фона сторон).
  - Режимы рабочего пространства: «Редактор бейджика», «Лист A4», «Предпросмотр печати».
  - `SettingsModal`: диалог настроек приложения (включение/отключение 3D-анимации, информация о локальном IndexedDB-хранилище).
  - `AutoSaveManager` и `HistoryManager`: стек истории действий (Undo/Redo с Ctrl+Z, Ctrl+Shift+Z) и отложенное сохранение изменений.
  - Проверена успешная сборка Vite и запущен dev-сервер на `http://localhost:3000/`.
