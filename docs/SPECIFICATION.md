# Badge Studio — Полное техническое задание (ТЗ)

**Версия документа:** 1.0  
**Статус:** Initial specification / MVP  
**Тип приложения:** Offline-first веб-приложение  
**Платформа:** Windows, браузеры Chrome и Edge  
**Рабочее название:** Badge Studio  

---

## 1. Описание проекта
Badge Studio — локальное веб-приложение для визуального создания, редактирования и печати студенческих бейджиков.
Приложение предназначено для сотрудников колледжа, которым необходимо подготовить бейджики для студентов, содержащие фотографии, персональную информацию и дополнительные данные на обратной стороне.

Основная задача проекта — заменить ручную работу в Adobe Photoshop простым визуальным редактором, ориентированным на подготовку карточек и их печать.

Пользователь должен иметь возможность:
- визуально редактировать дизайн бейджика;
- создавать лицевую и обратную стороны;
- добавлять фотографии;
- изменять положение и размеры элементов;
- переключаться между карточками;
- переворачивать бейджики с приятной анимацией;
- автоматически сохранять изменения;
- размещать карточки на листе A4;
- печатать обе стороны с правильным совмещением.

---

## 2. Главная концепция
1. **Редактор бейджика** — создание и редактирование отдельных карточек.
2. **Редактор листа A4** — визуальное размещение карточек и подготовка к печати.

---

## 3. Границы версии (MVP)
### Входит в MVP:
- Визуальный редактор карточки.
- Лицевая и обратная стороны карточки.
- Добавление, редактирование и удаление элементов (текст, фото, рамки, фигуры, QR).
- Работа с фотографиями (масштаб, позиционирование, маски/рамки).
- Flip Card Animation (CSS 3D Transform).
- Лист A4 с несколькими карточками (автораскладка и ручные колонки).
- Автоматическое сохранение (IndexedDB).
- Предварительный просмотр печати.
- Двусторонняя печать лицевой и обратной сторон с совмещением.
- Настройки размеров и расположения карточек (стандарты 90x55, 85x55, произвольный).
- Базовая история действий Undo/Redo.

### Не входит в MVP:
- Импорт Excel / CSV.
- Автоматическое сопоставление фотографий.
- Массовая генерация карточек из таблиц.
- Облачное хранилище и базы данных.
- Регистрация пользователей.
- AI-ретушь.

---

## 4. Стек технологий и ограничения
- HTML5, CSS3, JavaScript (ES Modules).
- Vite для локальной разработки и сборки.
- Fabric.js для холста и векторного редактирования.
- IndexedDB (проекты, карточки, изображения) + LocalStorage (настройки UI).
- CSS 3D Transform для анимации переворота бейджика.
- CSS Print Media для чистой подготовки к печати без элементов управления.
- Никаких внешних серверов, облаков или отправки персональных данных.
- 100% автономная локальная работа.
