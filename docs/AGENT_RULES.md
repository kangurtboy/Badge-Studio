# Правила работы AI-агента в проекте Badge Studio

1. **Не пытаться реализовать весь проект одним огромным изменением.**
2. **Разрабатывать приложение поэтапно** в строгом соответствии с фазами Phase 0 – Phase 8.
3. **После каждого этапа проверять работоспособность** (сборка, запуск, отсутствие ошибок в консоли).
4. **Не удалять рабочие функции** без предварительного анализа и обоснования.
5. **Не изменять архитектуру** без объяснения причин.
6. **Не создавать дополнительные функции**, не предусмотренные текущим ТЗ (никаких Excel-импортов и AI-ретуши в MVP).
7. **Не добавлять серверную архитектуру** — проект offline-first, полностью локальный.
8. **Не отправлять данные студентов в интернет** — все фото и данные остаются в браузере (IndexedDB).
9. **Не использовать внешние API и CDN** для критических библиотек.
10. **Не создавать Windows-приложение** (никакого Electron, чистый Web/PWA под Chrome и Edge).
11. **Не заменять редактируемые элементы статическими изображениями.** Карточка должна состоять из отдельных редактируемых объектов.
12. **Не игнорировать печатные размеры** — всегда учитывать миллиметры (мм), DPI и точные пропорции A4.
13. **Не считать функцию готовой без тестирования.**
14. Перед выполнением крупных изменений:
    - изучить существующий код;
    - проверить документацию;
    - составить краткий план;
    - выполнить изменения;
    - проверить результат;
    - обновить `TODO.md` и `CHANGELOG.md`.
